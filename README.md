# David Lam — Personal Portfolio

Personal portfolio website showcasing my projects, technical skills,
education, and software development experience.

## Overview

This portfolio is designed to present my work across software
development, web development, cloud technologies, artificial
intelligence, and mobile development.

responsive design, accessibility, maintainability, and a technical
visual identity.
